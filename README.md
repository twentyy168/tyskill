# tyskill

一组帮助普通人使用 AI、判断 AI 产出并承担真实任务的 Skills。

当前发布：`tys-ai-output-acceptance`。

## tys-ai-output-acceptance

AI 可以快速生成内容、代码、网站、数据分析、方案和自动化，但“生成完成”不等于“可以使用”。这个 Skill 会先把目标变成可观察的验收标准，获得用户确认后再检查证据，最后给出“通过／未通过／无法验收”的结论。

它会重点检查：

- 目标和验收标准是否一致；
- 事实、计算、行为、约束和外部动作是否有匹配证据；
- 失败会具体影响谁、造成什么、是否可恢复；
- 未通过时应该修什么、需要什么工具或授权、怎样复测；
- 销售型内容是否同时说明“为什么选择”和真实的“为什么现在行动”。

模型自查、多模型一致、换模型或接入 MCP 可以帮助发现线索，但不能单独证明产出已经正确。

## 安装

```bash
npx -y skills add twentyy168/tyskill -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $tys-ai-output-acceptance 验收这个 AI 产出，给出通过、未通过或无法验收的证据结论。

也可以直接说：

> AI 帮我做了一个带注册、登录和支付的网站。我不会编程，请帮我验收它能不能上线。只使用测试支付，不要部署。

Skill 会先给出目标拆解和验收标准草案。用户确认后，才会运行检查并形成结论。

## 适用范围

适合验收已经存在的 AI 产出。不用于单纯生成内容、编写提示词、训练模型或比较模型排行榜。

医疗、法律、投资、人身安全等高风险专业结论仍需合格专业人员复核。验收请求默认只授权检查，不自动发布、付款、发送消息、连接账号或修改生产系统。

## 运行依赖

- 支持 Agent Skills 的客户端；
- 部分验收任务需要浏览器、项目文件、测试环境、原始信源或专业复核，Skill 会在缺失时明确标为未验证。

## 内容

本仓库只发布运行这个 Skill 所需的文件。本地评测样本、预期答案和运行记录不包含在公开包中。
